# Планировщик дедлайнов

Учебный проект по УП.09.  веб-приложение для учёта учебных задач и сроков сдачи.

## Языки
- HTML — структура интерфейса.
- CSS — адаптивная вёрстка.
- JavaScript — логика приложения.
- localStorage — сохранение данных в браузере без отдельной базы данных.

## Возможности
- Добавление задачи: название, предмет, дата сдачи, приоритет.
- Автоматическое распределение на «Просрочено», «На этой неделе», «Позже».
- Красная отметка для просроченных задач, оранжевая — для задач со сроком в ближайшие два дня.
- Подсчёт календарных дней до срока: сегодня — 0, завтра — 1.
- Сортировка по дате внутри групп.
- Поиск по названию и фильтр «Все / Активные / Сдано».
- Отметка «Сдано» с записью фактической даты выполнения.
- Редактирование и удаление с подтверждением.
- Сохранение после обновления страницы.

## Запуск локально
1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и этот README.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. После публикации скопируйте адрес сайта в отчёт и презентацию.

## Хранение данных
Задачи сохраняются в localStorage текущего браузера и устройства. Они не синхронизируются между разными устройствами и браузерами. Очистка данных сайта в браузере может удалить сохранённый список.

## Проверка
Рекомендуемые проверки приведены в отчёте. После публикации выполните их в браузере и добавьте фактические скриншоты и ссылку на сайт.
